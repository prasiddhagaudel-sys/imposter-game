## 🎮 How to Play

1. **Setup Game**: Enter player names and select the number of Imposters.
2. **Pass & Reveal**: Each player holds down their card privately:
   - **Civilian Players** see the secret word.
   - **Imposter Players** receive a subtle, indirect hint word instead!
3. **Discuss & Question**: Take turns giving one-word clues or asking questions without giving away the exact word.
4. **Vote**: When the discussion timer ends, vote to identify and eliminate the Imposter!
